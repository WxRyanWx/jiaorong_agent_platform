# 技能模板

这是一份模板技能，用来演示「技能 = 写给模型看的操作说明」：模型激活技能后会先读本文件，再按下面的步骤回答。正式开发时请把整份文件换成你自己的技能。

## 换成你自己的技能

1. 把目录 `skill/example/` 改名成你的技能名，只用小写字母、数字和单个横线，例如 `skill/weekly-report/`。
2. frontmatter 的 `name` 改成与新目录名完全一致；两者不一致宿主会认不出这份技能。
3. `description` 写清「什么时候必须用这个技能」，模型靠它判断要不要激活，例如「用户提到本周进展、周报、小结、汇报时必须使用」。
4. 把下面的「正文示例」整段换成你的步骤与输出格式，并删掉本节。
5. 同步改两处引用，技能名都要与目录名一致：
   - `node/config.js` 的 `SKILLS`（`agent.create` 下发给宿主）与 `DEFAULT_SKILL`（每轮必读的那一份）
   - `web/src/constants.ts` 的 `CHAT_SLASH_ITEMS`（输入框 `/` 菜单）

加第二份技能：在 `skill/` 下再建一个目录，把目录名追加进 `SKILLS`。`SKILLS` 的第一份由 `DEFAULT_SKILL` 指定为每轮必读，其余由模型按 `description` 自行判断是否改读。

技能全名是 `app.<应用 id>.<目录名>`，由宿主拼；应用里只写目录名，不要自己拼全名。

## 正文示例（替换成你的步骤）

回复第一行必须写：【示例技能】

1. 先读本文件，再按步骤执行。
2. 按「结论 / 依据 / 待确认」三段输出。
3. 用户没给的信息不要编造，缺什么就列出来。
