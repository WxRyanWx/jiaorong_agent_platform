Jiaorong CLI 速查表

只列首版已验收口径。图片识别和 Shell 不在其中。

启动顺序

command -v jiaorong-cli
jiaorong-cli --version
jiaorong-cli doctor --output-format json
jiaorong-cli models list --output-format json

功能

目的参数关键点
人读正文--output-format textstdout 只有成功正文
脚本终态--output-format json一个 JSON；同时检查 exit 和 status
实时事件--output-format stream-jsoninit 第一、result 最后且各一次
继续会话--resume SESSION_ID同一 Session 不并发
文本附件--file PATH重复传入；首版不依赖图片
外部目录--add-dir ABS_PATH不扩大 Project Root 的其他边界
文件操作--permission-mode full_access仍只在授权根内；无 Shell
超时--timeout SECONDS走真实远端取消并等待落定

可靠成功条件

exit = 0
result.status = success
result.error = null
result.sessionId 非空

退出码

0success
1model/tool/timeout/internal
42input/argument/attachment/protocol
53turn limit
130SIGINT cancellation path

不要：从 Home 或 / 运行文件任务；猜模型 ID；把 stderr 混进 JSONL；把 full_access 当成全盘权限；依赖图片或 Shell。
