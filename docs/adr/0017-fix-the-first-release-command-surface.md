# Fix the first-release command surface

The first Jiaorong CLI release will expose foreground Headless Runs with new and resumed sessions; authentication login, status, and logout; model discovery; session listing and deletion; doctor, update, and version commands; and the agreed output, model, permission, directory, attachment, turn-limit, and timeout arguments. TUI, background jobs, daemon, server, ACP, MCP, plugins, subagents, and custom Agent commands are explicitly outside the first-release contract.
