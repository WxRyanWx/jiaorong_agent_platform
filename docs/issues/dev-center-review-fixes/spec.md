# 开发者中心审查问题修复

## 需求

- 发布成功后关闭发布弹窗，避免同一请求结束后还能重复提交。
- 换账号时保留新身份同步的本地登记名单。
- 发布 IPC 异常时提示发布失败，而不是应用缺失。
- 本地登记存储键与主进程换人判断使用同一身份规则。

## 验收标准

- 发布成功后弹窗关闭并 toast；发布中用户取消、遮罩关闭与 Esc 仍被拦截。
- 换账号清理旧调试窗口前先清空旧内存名单，新身份随后的同步不会被覆盖。
- IPC 抛错时展示发布失败语义。
- 同一登录身份补充或变更手机号但不变更 userName 时，不切换本地登记键。

## 约束

- 不改变发布包格式；深层 app.json 的行为收紧保持现状。
- 不接入真实发布接口。
- 不做跨账号历史登记迁移。

## 非目标

- 放开 zip 内深层 app.json。
- 重构开发者中心状态管理。
