# 开放平台发布与插件中心联动修复

## 背景

开放平台接入真实接口后，联调暴露 6 个问题：技能详情接口被误跳过、
发布弹窗要求用户重复选 zip、更新弹窗技能类型无法修改、更新后市场
更新按钮消失、交融应用安装后无卸载按钮、app.json 的 source 字段未
透传到后端。

## 目标

1. 技能详情页对开放平台技能也调用 `GET /skill/{id}`，容忍后端 500，
   接口补齐 `source` 后自动生效。
2. 发布（草稿 → 发布）复用创建时记住的 zip，不再让用户重复上传；
   只有更新必须选新包。发布请求仍带 file，后端契约不变。
3. 更新弹窗里技能类型下拉可用且可修改。
4. 技能安装记录同时按市场名与资产 id 落键，资产展示名被后端覆盖后
   已装关联与更新判定不丢。
5. 交融应用从市场安装后，开发者能看到卸载按钮；生产安装副本与
   开发者工作区按目录区分。
6. app.json 的 source（builtin/store）透传到发布 manifest，缺省 store。

## 非目标

- 不改全局 MCP 启停链路。
- 不解决后端版本号倒退 / 草稿包不落库等后端缺陷，只记录到问题清单。
- 不调整卸载权限模型（仍为开发者可卸载）。

## 验收

- 发布弹窗（draft）不出现 zip 行且能直接发布；更新弹窗必须选新 zip。
- 更新弹窗可切换技能类型。
- 开放平台技能详情页发起 `GET /skill/{id}` 请求。
- 市场安装的交融应用对开发者显示卸载按钮。
- app.json source=builtin 发布后后端列表回显 builtin。
