# 空的新建会话失败回滚

## 用户问题

侧边栏出现多条 `New Chat`，点击后页面为空。本地数据确认这些会话均为 0 条消息，说明首条消息未成功落库，但会话记录已保留。

## 目标

- 新建会话的首轮初始化失败且没有任何消息时，删除该会话并通知 UI。
- 若首轮失败时消息已存在，保留会话，避免丢失用户输入。

## 验收标准

- 首轮启动抛错且 `hasMessages=false` 时，会话树被删除并发出 deleted 通知。
- 首轮启动抛错且消息已存在时，不删除会话。
- 现有取消清理行为保持不变。

## 非目标

- 不自动清理历史空会话。
- 不改变 ACP 草稿会话复用逻辑。
