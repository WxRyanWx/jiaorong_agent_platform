# 记忆设置页交互调整

## 目标

记忆页工具栏直接开关长期记忆；配置入口和诊断 Tab 先藏起来，代码保留，方便以后再放开。

## 验收

1. 原「配置 / 开启记忆」按钮仍在源码中，用 `v-if` 隐藏（不能对 `DcButton` 用 `v-show`）。
2. 按钮旁新增「长期记忆」开关，写入现有 `memoryEnabled`。
3. 配置面板里原来的长期记忆开关隐藏，逻辑不删。
4. 「诊断」Tab 隐藏；记忆 / 指令（及人格）仍在。
5. 空状态「开启记忆」走同一个开关写入，不再打开已隐藏的配置面板。
6. 状态栏嵌入模型文案可按开关隐藏，悬停 title 仍保留。

## 非目标

- 不改记忆读写、召回、重建索引。
- 不删除配置面板其它字段。
