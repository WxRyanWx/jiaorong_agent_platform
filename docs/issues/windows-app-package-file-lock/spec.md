# Windows 安装包被安全中心短暂锁住

## 问题

交融应用的安装包解压后，客户端立刻把临时目录改名到 `~/.jiaorongchat/apps/<id>`。卸载则一次性删除该目录。

Windows 安全中心会在 exe 和 dll 落地后立刻打开它们做扫描。扫描期间移动或删除目录返回 `EPERM`。扫描时长不固定，所以安装大约三次里成功一次。卸载删到被锁的文件就停下，目录只剩一半。任务管理器里看不到应用进程，占文件的是系统扫描进程。

用户不能为了安装去手动加排除项或删残留目录。

## 验收

1. Windows 上移动目录遇到 `EPERM`、`EBUSY`、`EACCES`、`ENOTEMPTY` 时先重试，仍失败则复制到目标目录，再尽力删掉临时目录。安装结果不依赖用户处理扫描锁。
2. 目标目录已经存在时立即失败，不把「目录已存在」当成扫描锁空等。
3. 卸载和覆盖安装前的删除按同一规则重试，扫描放开后把剩余文件继续删完。
4. 非 Windows 上的 `EPERM` 仍立即失败。
