# Windows 卸载时安装目录里的程序还占着文件

## 问题

`cccc-roadbed-ai` 的 `spawn` 是 `launch.cmd`。打开应用后，它会启动 `payload\roadbed-ai.exe`。这是一个 Electron 程序，运行期间会占住 `payload\resources\app.asar`。

卸载只在客户端还记着这次启动的进程时，才用 `taskkill /T` 结束那棵进程树。下面几种情况树里已经没有这个 exe，卸载却直接删目录：

- 客户端重启过，内存里的进程记录没了，exe 还在。
- Electron 重新拉起自己后，新进程不再挂在原来的 `cmd.exe` 下面。
- `launch.cmd` 已经退出，客户端以为应用没在运行。

这时删除会一直失败：`EBUSY: resource busy or locked, rmdir '...\app.asar'`。安全中心的短暂锁已经会重试；进程不退出，重试到超时也删不掉。

## 验收

1. Windows 上，删除已安装目录之前，先结束可执行文件位于该目录内的进程。不结束目录以外的进程，也不结束客户端自己。
2. 客户端已经不记得这次启动时，仍然按安装目录查找并结束。
3. 结束之后仍走原来的删除重试。进程退出后句柄还会多占一会儿，这段时间要能删完。
4. 其他系统不扫描进程。

## 非目标

不要求用户手动结束进程或删除目录。不改应用包里的 `launch.cmd`。
