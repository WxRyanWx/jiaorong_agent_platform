# 侧栏点击无响应 / 首页加载极慢

## 用户现象

- 点击左侧菜单长时间无反应
- 首页空白约 30s 才出来

## 根因

侧栏切换与欢迎页会 `await forceRevalidateAuthSession()` → 同步请求 `/sys-user/userInfo`。  
鉴权 axios 默认 `timeout: 150000`（150s）。测试服/代理慢时，UI 被网络请求堵住。

## 验收

- 有 token 时侧栏切换立即跳转，不因鉴权网络阻塞
- 会话校验请求使用短超时（数秒级）；超时/网络错误保留本地登录态（既有策略）
- 401 仍跳登录
- 用户自建 agent 行为不变

## 非目标

- 不改登录页主流程超时策略（账号密码登录可保留较长 timeout）
