# 聊天首屏加载变慢

## 目标

打开已有会话时更快出首屏；上滑再补历史。保持当前不回跳。

## 验收

1. 首次 restore 只要 10 条，不再先兜底 40/100 条。
2. 上滑分页每次 20 条。
3. 流式结束后刷新，保留已经在窗口里的条数，不无故扩到 100。
4. 用户进入距顶预取区时立即静默加载下一页，不等滚动停住、不要求再划一次。像素阈值维护在 `@jiaorong/chat/messageWindowPolicy`。
5. 上滑仍不回跳；最后一条下面不留大片空白。保留知识库、思考条首屏收起、列表关闭 markdown 虚拟化。
6. 预取请求未结束或补偿未写完时，继续上滑不取消补偿、不连发第二页。

## 非目标

- 不改列表 `min-height`、滚动中 overflow-anchor。
- 不重开 markdown 虚拟化 / 已结束消息的 batch-rendering。
- 程序滚动（补偿、搜索跳转）不触发预取。
