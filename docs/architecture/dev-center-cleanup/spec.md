# 开发者中心整理

## 目标

- 修复发布弹窗并发期间的状态串扰。
- 统一首次发布与更新发布的应用 ID 语义。
- 收敛生产/调试切换的重复实现。
- 让开发者中心卡片展示当前 `app.json` 的最新信息。
- 优化发布 zip 的解析与临时文件处理。
- 让调试窗口侧边栏不再为了图标触发远端配置刷新。
- 按登录身份隔离浏览器本地登记名单。
- 更新过期 SDD 文档，移除已删除的下载与独立开发者中心窗口描述。

## 验收标准

- 发布请求返回时只影响发起它的弹窗实例。
- 发布最终 `app.json.id` 必须等于本地登记应用 ID。
- 生产切换只保留一份确认与关闭逻辑。
- 卡片名称、版本、描述与当前清单一致。
- zip 回写只解压一次，占位发布结束即删除临时包。
- 调试窗口侧边栏取当前应用信息不触发 OSS 刷新。
- 不同登录身份读取不同的本地登记存储键。
- 开发者中心 SDD 与当前代码结构一致。

## 约束

- 不接后端发布接口，不新增服务端归属校验；应用归属必须由后端最终裁决。
- 不改变普通应用安装、卸载、打开语义。
- 不做大型目录重构。

## 非目标

- 替换 localStorage 为服务端数据源。
- 实现发布上传与审批流。
- 改造开发者中心页面视觉。
