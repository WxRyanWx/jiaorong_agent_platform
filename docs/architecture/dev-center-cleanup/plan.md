# 开发者中心整理方案

## 执行顺序

1. P0 发布弹窗并发守卫。
2. P0 首次发布 ID 一致性。
3. P1 生产切换函数收敛。
4. P1 卡片状态以当前 `app.json` 为准。
5. P1 zip 单次解析与临时文件清理。
6. P1 调试窗口侧边栏轻量取数。
7. P2 本地登记按登录身份隔离。
8. P2 清理开发者中心过期 SDD 文档。

## 兼容性

- 发布 IPC 入参不变；新增更严格的服务端式兜底校验。
- 开发者中心列表返回结构不变。
- 调试窗口侧边栏新增专用 IPC，不复用会刷新 OSS 的列表 IPC。
- 开发者中心尚未发布生产，不处理历史全局 localStorage 登记；当前实现按登录身份重新登记，不做跨账号迁移。

## 验证

- 每项修改后做两轮代码路径复核。
- 每项通过后 `git add` 该项相关文件。
- 最终运行开发者中心专项测试、Jiaorong 主进程/渲染端测试、typecheck、lint、i18n 与格式检查。
