# 关于设置页配色

## 用户需求

- 关于页面头部“系统”文字颜色为 `#5C78A0`。
- 产品说明“交融超级智能体平台是一个跨平台AI客户端，致力于让更多人便捷地使用AI。”
  颜色为 `#5C78A0`。
- 页面按钮背景为 `#F7FAFE`。
- 页面按钮边框为 `1px solid #D5E0ED`。
- 检查更新按钮在“检查中”禁用状态仍保持指定背景、边框和不透明显示。
- 检查更新按钮图标颜色为 `#5C78A0`。

## 目标

统一关于设置页的辅助文字和按钮视觉。

## 验收标准

- 页面眉题和产品说明使用 `#5C78A0`。
- 关于页面内按钮使用指定背景和边框。
- 检查更新按钮在检查中不因 disabled 状态变为半透明。
- 检查中的旋转图标显示为 `#5C78A0`。
- 产品标题、版本号、更新状态和弹窗样式保持原样。

## 约束

- 宿主只增加语义 class，样式集中在 `src/jiaorong_src/brand/theme.less`。
- 不改变页面交互、布局和文案。
- 不运行格式化，保留原文件风格。

## 非目标

- 不调整其他设置页面。
- 不修改更新检查逻辑。

## 开放问题

无。
