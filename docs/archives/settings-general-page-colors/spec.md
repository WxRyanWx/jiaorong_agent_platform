# 常规设置页配色

## 用户需求

- `settings-general-page` 头部“基础”眉题文字颜色为 `#5C78A0`。
- 页面图标颜色为 `#5C78A0`。
- 页面按钮边框为 `1px solid #D5E0ED`。
- Switch 未选中背景色为 `#D5E0ED`。

## 目标

统一常规设置页的眉题、图标、按钮和 Switch 未选中态视觉。

## 验收标准

- 仅常规设置页头部“基础”眉题文字使用 `#5C78A0`，其他文字保持原样。
- 常规设置页图标使用 `#5C78A0`。
- 常规按钮使用 `1px solid #D5E0ED`，Switch 不套用按钮边框。
- Switch 在 `unchecked` 状态使用不透明的 `#D5E0ED`。

## 约束

- 宿主组件只增加语义 class，具体样式写入 `src/jiaorong_src/brand/theme.less`。
- 不改变交互、布局和文案。
- 不运行格式化，保留原文件风格。

## 非目标

- 不调整其他设置子页面。
- 不改变 Switch 已选中状态。
- 不改变错误提示等语义状态色。

## 开放问题

无。
