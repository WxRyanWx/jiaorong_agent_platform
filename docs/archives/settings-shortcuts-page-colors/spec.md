# 快捷键设置页配色

## 用户需求

- 快捷键设置页所有图标颜色为 `#5C78A0`。
- 页面头部“系统”文字颜色为 `#5C78A0`。
- 快捷键文本框背景为 `#F7FAFE`。
- 快捷键文本框边框为 `1px solid #D5E0ED`。

## 目标

统一快捷键设置页图标和快捷键录入框的品牌视觉。

## 验收标准

- 页面头部“系统”以及页面内 Iconify、Lucide 图标显示为 `#5C78A0`。
- 每条快捷键的显示/录入框使用 `#F7FAFE` 背景和 `#D5E0ED` 边框。
- 错误状态、录制状态及按钮交互保持原样。

## 约束

- 宿主只增加语义 class，样式集中在 `src/jiaorong_src/brand/theme.less`。
- 不运行格式化，保留原文件风格。

## 非目标

- 不修改快捷键录制、冲突检查或保存逻辑。
- 不调整其他设置页面。

## 开放问题

无。
