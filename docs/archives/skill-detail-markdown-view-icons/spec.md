# Skill 详情页 Markdown 视图图标

## 需求

使用交融品牌切图替换 Skill 详情页 Markdown 区域的“预览”和“源码”Lucide 图标。

## 验收标准

- 预览按钮默认使用深色 Preview 图标，选中时使用蓝色 Preview 图标。
- 源码按钮默认使用深色 Code 图标，选中时使用蓝色 Code 图标。
- 使用 `@2x` 图片资源，并分别按 20px 和 16px 的设计尺寸展示。
- 按钮的切换行为、无障碍标签、布局和背景状态保持不变。

## 约束与非目标

- 图片统一存放在 `src/jiaorong_src/brand/icons/skill-detail`，目录和文件名必须使用
  语义化英文命名，不保留设计稿中文切片目录。
- 不改变 Markdown 渲染与源码读取逻辑。

## 开放问题

无。
