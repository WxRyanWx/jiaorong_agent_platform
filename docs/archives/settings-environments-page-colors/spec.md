# 目录环境页配色

## 用户需求

- 目录环境页右侧的“Agent 设置”文字颜色为 `#5C78A0`。
- 说明“查看会话使用过的项目目录，并快速打开或设为默认目录。”颜色为 `#5C78A0`。
- 项目目录路径（如 `/Users/yanxia1/projects/20k`）颜色为 `#5C78A0`。
- 页面图标颜色为 `#5C78A0`。
- 页面按钮边框为 `1px solid #D5E0ED`。

## 目标

统一目录环境页的辅助文字、路径和按钮边框视觉。

## 验收标准

- 页面眉题、页面说明、目录路径和图标显示为 `#5C78A0`。
- 页面普通按钮使用 `1px solid #D5E0ED`。
- Switch 不套用普通按钮边框。
- 页面标题、目录名称、会话统计及状态颜色保持原样。

## 约束

- 宿主仅增加语义 class，具体样式集中在 `src/jiaorong_src/brand/theme.less`。
- 不改变页面交互、布局和文案。
- 不运行格式化，保留原文件风格。

## 非目标

- 不调整其他设置页面。
- 不修改目录数据或默认目录逻辑。

## 开放问题

无。

## 修复记录

- 页面作用域 class 缺失时，说明文字、路径和按钮边框规则无法命中；页面根组件必须保留
  `.settings-environments-page`。
