# 智能体设置控件配色

## 用户需求

- 选中的智能体卡片背景为 `#F7FAFE`，圆角为 `12px`，边框为 `2px solid #006EFF`。
- 智能体页下拉选择触发器仅在聚焦或展开时使用 `#F7FAFE` 背景和
  `1px solid #D5E0ED` 边框。
- 页面所有 Input/Textarea 聚焦状态使用 `#F7FAFE` 背景和 `#D5E0ED` 边框。
- Switch 未启用背景为 `#F7FAFE`，启用背景为 `#006EFF`，边框均为 `#D5E0ED`。
- 页面所有常规边框颜色统一为 `#D5E0ED`。
- 选中的头像类型按钮背景为 `#F7FAFE`，边框为 `2px solid #006EFF`。
- 选中的头像类型标题文字颜色为 `#006EFF`。
- 智能体列表中的“已启用”状态文字颜色为 `#33B737`。
- 智能体列表和编辑器头部的头像容器背景为 `#E8F1FF`。

## 目标

统一智能体设置页的选中卡片、下拉选择框和启用态 Switch 视觉。

## 验收标准

- 左侧当前选中智能体卡片应用指定背景、圆角和蓝色边框。
- 除当前选中智能体卡片外，页面常规边框统一显示为 `#D5E0ED`。
- 当前选中的头像类型按钮应用指定背景和蓝色边框。
- 当前选中的头像类型标题显示为蓝色。
- 仅“已启用”状态显示为绿色，“已禁用”保持原色。
- 两处智能体头像容器使用相同浅蓝背景。
- 模型、默认项目目录、权限模式和子智能体目标等选择框仅在选中/展开状态应用指定效果。
- Input/Textarea 聚焦时应用指定样式；Switch 通过不同背景明确区分启用和未启用。
- “启用状态”整行容器、未选中卡片和其他按钮保持原样。

## 约束

- 宿主只增加语义 class，样式集中在 `src/jiaorong_src/brand/theme.less`。
- 不改变交互、布局和文案。
- 不运行格式化，保留原文件风格。

## 非目标

- 不调整其他设置页面。
- 不修改智能体配置数据或保存逻辑。

## 开放问题

无。

## 修复记录

- Switch 显式挂载 `.settings-agent-switch`，避免组件自带状态工具类覆盖品牌背景。
