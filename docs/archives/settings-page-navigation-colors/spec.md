# 设置页导航配色

## 用户需求

调整独立设置页的基础配色：

- 左侧导航栏背景色为 `#EFF5FF`
- 左侧导航图标颜色为 `#5C78A0`
- 当前选中导航项背景色为 `#E5EFFF`
- 顶部栏背景色为 `#EFF5FF`

## 目标

让设置页导航区域与顶部栏使用统一的浅蓝视觉，并清晰区分当前选中项。

## 验收标准

- 设置页左侧导航栏使用不透明的 `#EFF5FF`，不叠加原有半透明背景工具类。
- 所有左侧导航图标显示指定颜色。
- 当前路由对应的导航项显示指定选中背景色。
- 导航项悬停效果与选中效果一致，背景色为 `#E5EFFF`、文字颜色为黑色。
- 当前选中导航项的文字颜色为黑色。
- 设置页顶部拖拽栏显示指定背景色。
- 原有导航、窗口拖拽和关闭按钮交互保持不变。

## 约束

- 遵循 `src/jiaorong_src/HOST_TOUCHPOINTS.md`：宿主只挂语义 class，品牌样式集中在
  `src/jiaorong_src/brand/theme.less`。
- 不新增用户可见文案。
- 保持宿主文件原有格式和代码风格，不运行格式化。

## 非目标

- 不调整主窗口侧边栏。
- 不改动设置页内容区配色。
- 不改变深色主题的其他设计。

## 开放问题

无。
