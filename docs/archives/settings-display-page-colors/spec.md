# 显示设置页配色

## 用户需求

- 显示设置页头部“基础”文字颜色为 `#5C78A0`。
- 页面图标颜色为 `#5C78A0`。
- 页面按钮和下拉框边框为 `1px solid #D5E0ED`。
- Switch 未选中背景色为 `#DDE5EF`。
- 页面描述文字颜色为 `#5C78A0`。
- “重置为默认”按钮背景色为 `#F7FAFE`。
- 语言、正文字体和代码字体选择框背景色为 `#F7FAFE`。

## 目标

统一左侧导航“显示设置”页面的辅助视觉样式。

## 验收标准

- “基础”、图标和描述文字显示为 `#5C78A0`。
- 页面内普通按钮及下拉触发器使用 `#D5E0ED` 边框。
- Switch 不套用普通按钮边框，未选中背景为不透明的 `#DDE5EF`。
- “重置为默认”按钮显示 `#F7FAFE` 背景。
- 页面选择框显示 `#F7FAFE` 背景。
- 页面标题、主要标签、Switch 已选中状态和弹窗样式保持原样。

## 约束

- 宿主只增加语义 class，具体样式集中在 `src/jiaorong_src/brand/theme.less`。
- 不运行格式化，保留现有文件风格。

## 非目标

- 不调整其他设置页面。
- 不修改页面交互、布局和文案。

## 开放问题

无。
