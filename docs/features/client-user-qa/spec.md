# 客户端高频问答 QA

## 需求

面向客户端用户整理 30 条高频问答，重点覆盖日常使用、功能入口和常见问题排查；可涉及快速开始、交融应用、技能、连接器和 CLI 的客户端使用方式。
问答不包含登录、退出这类过于基础的账号操作，不按分类列展示，也不继续偏重交融应用开发。

## 验收标准

- 问答覆盖当前客户端文档与实际功能入口。
- 每条问题都对应明确、可执行的答案。
- 输出 30 条问答，保存到用户下载目录。
- 以当前客户端真实可操作功能为准，不写入用户不可见的模型选择、联网搜索等入口。
- 普通用户不能选择模型；模型相关内容仅保留“调整当前默认模型参数”。
- 交融应用“卸载”仅开发者可见，普通用户问答不承诺可卸载。
- 删除过于简单的账号类问答，去掉分类列。
- 问题主体以“客户端使用”为主，包含对话、附件、知识库、设置、快捷键、插件中心与更新等日常场景。
- CLI 相关内容不虚构，明确标注“暂未提供文档”。

## 非目标

- 不新增客户端功能或修改业务代码。
- 不重写现有产品文档。
