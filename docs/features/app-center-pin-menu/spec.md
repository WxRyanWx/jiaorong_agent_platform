# 交融 AI 应用钉到左侧菜单（spec）

## 背景

开放平台上架的交融应用默认 `slot` 为 `app-center`，只出现在插件中心「交融AI应用」列表。`app.json` 的 `slot=menu` 会进左侧菜单，但上架时并不把这件事告诉用户。

## 用户需求

1. 交融 AI 应用卡片右上角、安全对号旁边增加钉图标。
2. 鼠标移上去显示说明；已安装的应用点击后出现在左侧菜单。
3. 应用更新、重新下载安装包之后，钉仍然在。
4. 卸载应用后，左侧菜单里的这项一起消失。

## 决策

- 不改安装包里的 `app.json`。更新安装使用覆盖解压，包内 `slot` 会被发布包写回。
- 钉是本机用户偏好，按应用 id 记在 `~/.jiaorongchat/pinned-menu-apps.json`。更新只换安装包，id 不变，钉还在。
- 发布包本身 `slot=menu` 的应用继续由清单进菜单，钉按钮只表示「已在左侧菜单」，不能把发布方的菜单位取消掉。
- 再点一次已钉上的应用，取消钉。
- 未安装时可以看见钉，点击只提示先安装，不写入偏好。
- 卸载成功后删掉对应 id。没装上的应用本来就不会进左侧菜单。

## 验收标准

- 已安装且 `slot` 不是 `menu` 的应用，点击钉后出现在左侧菜单；悬停文案为「钉到左侧菜单」。
- 已钉上的悬停文案为「已钉在左侧菜单，点击取消」，再点后从菜单消失。
- 覆盖安装新版本后，同一 id 仍在菜单里。
- 卸载成功后，菜单项消失，且偏好里不再保留该 id。
- 未安装应用点击钉时提示「安装后可钉到左侧菜单」。

## 非目标

- 不改开放平台上架表单，也不把用户的钉写回发布包。
- 不让用户取消发布包声明的 `slot=menu`。
- 开发者中心本地工作区包不进这条菜单。
