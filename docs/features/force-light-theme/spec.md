# 启动强制浅色主题

## 用户需要

产品取消应用内主题色调切换，统一浅色系；入口已隐藏。用户若曾保存 dark/system，打开应用时应自动回到浅色。

## 目标

应用启动时若 `appTheme` 不是 `light`，强制设为 `light` 并持久化。

## 验收标准

1. 本地已是 `dark` 或 `system` 时，冷启动后界面为浅色，且配置变为 `light`。
2. 已是 `light` 时行为不变、无多余闪烁。
3. 侧栏/外观页主题入口保持隐藏（既有 H36/H37）。

## 约束

- 判定与常量放 `@jiaorong/brand`；宿主仅在 `ConfigPresenter.initTheme` 薄调用。
- 不改 Agent 工具中途改主题的行为（下次启动仍会被拉回 light）。

## 非目标

- 不删除 dark 相关 CSS / 组件类名。
- 不恢复主题切换 UI。

## 开放问题

无。
