# 技能详情页

## 目标

基于应用实际技能目录 `~/.jiaorongchat/skills` 中已有技能构造前端展示数据，实现需求文档第 3 节的技能详情页面，并让技能列表可以进入对应详情。

## 验收标准

- 技能列表展示当前 `~/.jiaorongchat/skills` 中的全部唯一技能名，点击可进入详情页。
- 选择若干真实技能 Mock 为“用户安装”来源，其余作为“技能广场”来源。
- 未安装详情只展示技能名称、技能描述和安装按钮。
- 点击安装后显示安装中状态，完成后切换为已安装详情。
- 已安装详情展示技能名称、默认开启的启停开关、描述和操作区。
- 操作区包含使用、打开文件夹和卸载技能；打开文件夹和卸载均有 Tooltip。
- 点击打开文件夹后，系统文件管理器打开当前已发现技能的实际目录。
- 技能数据使用与 SkillPresenter 一致的真实技能名，打开文件夹时能够命中实际 `skillRoot`。
- Markdown 源文本与渲染内容读取已安装技能目录中的真实 `SKILL.md`，不使用 Mock 内容。
- 卸载后当前页切换为未安装状态。
- 当前阶段卸载使用 Mock，仅更新页面内存状态，不删除技能目录及源文件；真实 SkillClient 卸载逻辑继续保留以便后续启用。
- 卸载成功 Toast 仅显示“已卸载”，并位于页面上方居中位置。
- 技能广场技能卸载后留在当前详情页并切换为未安装状态。
- 用户自行安装技能卸载后返回技能中心列表页。
- 每个技能广场技能提供多条“试一试”预设提示词，点击任意一条均携带当前技能进入新的通用对话。
- 用户自行安装技能详情不展示描述和“试一试”模块。
- 源文件支持 Markdown 源文本和渲染效果两种查看方式。
- 安装、启停、安装状态检测和卸载均保持 Mock；打开文件夹仍为真实系统文件操作。

## 非目标

- 接入 SkillHub 或真实技能市场接口。
- 执行真实安装操作。
- 改造技能运行时的全局启停机制。

## 约束

- 新业务代码全部位于 `src/jiaorong_src/skills`。
- 复用现有 `startGeneralChatWithSkills` 进入通用对话。
- 用户可见文本使用国际化键值。
- Mock 状态只在当前渲染进程内保留。
