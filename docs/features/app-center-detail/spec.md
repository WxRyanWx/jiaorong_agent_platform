# 插件中心交融应用详情（spec）

## 背景

插件中心「交融AI应用」列表目前只在卡片上展示名称、版本、简介、提供方和安装操作。用户需要查看单条应用的详情，并看到该应用已通过安全检查。

## 用户需求

1. 每张应用卡片增加「详情」按钮。
2. 点击后从右侧打开侧边栏，交互与开放平台反馈抽屉一致：遮罩、右侧面板、可关闭。
3. 详情展示当前列表已有的数据，并按应用市场详情的常见结构排版：图标与名称、版本、提供方、简介、安装状态、上架与更新时间、分发位置、安装包校验。
4. 卡片版本号右侧增加绿色对号。鼠标移上去显示「该应用已通过安全检查」。
5. 同一条安全检查说明出现在详情里。

## 验收标准

- 每张卡片都有「详情」，点击打开右侧面板，点遮罩、关闭按钮或 Esc 可关掉。
- 面板内容来自当前卡片，不编造评分、下载量或截图。
- 有上架时间、最近更新或安装包校验值时才展示对应行。
- 版本号右侧有绿色对号，悬停文案为「该应用已通过安全检查」。
- 详情里有安全检查说明。

## 应用大小

- 已安装：统计本机解压目录。
- 未安装：向下载地址询问 zip 字节数。响应头有 `Content-Length` 或 `Content-Range` 就直接用。
- 两种头都没有时，把安装包按块读完并累计字节，不落盘。同一地址在本次运行里只读一次。
- 空的 `Content-Length` 不能显示成 `0 B`。读不到时显示「未安装，安装后才能看到」。

## 视觉

详情抽屉白底，版式与列表卡片一致：名称、版本、简介，信息逐行左标签右内容。安全检查紧挨版本号，只显示绿色对号和「该应用已通过安全检查」。底部按钮与列表卡片同一套配色：打开为实心主按钮，安装、更新、卸载为线框按钮。「由…提供」放在这一排的左侧。

## 非目标

- 不接新的安全检查接口，对号是列表上的展示标记。
- 不改开放平台开发侧的应用卡片。
- 市场接口没有体积字段时，不编造大小。
