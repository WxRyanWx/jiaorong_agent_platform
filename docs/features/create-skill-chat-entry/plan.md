# 实施计划

1. 扩展一次性新对话启动参数，使其支持可选的待激活技能名称。
2. 由 `ChatInputBox` 暴露已有的技能激活动作，并在 `NewThreadPage` 中消费启动参数里的技能。
3. 在交融公共 `utils` 中提供“携带技能启动通用对话”的方法，统一完成启动意图写入、通用智能体切换、新会话创建和路由跳转。
4. 在技能中心添加“新建技能”下拉菜单，通过公共方法携带 `skill-creator` 和预设提示词进入通用对话。
5. 补充国际化文案和聚焦测试，执行仓库质量检查。

本功能不需要新增 IPC，也不产生新的持久化数据。新增的启动参数字段为可选字段，因此已有的 Deeplink 调用保持兼容。

## 代码边界

- 新建技能入口、提示词、技能名称和跳转编排均位于 `src/jiaorong_src`。
- 本次扩展已有技能模块，不新增独立业务模块，因此无需新增 `module.ts` 或修改 `runtime/discover.ts`。
- 本功能不调用自有后端，因此不新增 `api/` 代码。
- `src/renderer` 仅扩展宿主通用对话对“待激活技能”启动参数的消费能力；涉及路径已登记到 `src/jiaorong_src/HOST_TOUCHPOINTS.md`。
