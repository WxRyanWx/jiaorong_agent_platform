# 创建技能对话入口

## 目标

引导用户从技能中心进入新的通用对话，并自动选中 `skill-creator` 技能、预填技能创建提示词。

## 验收标准

- 技能中心右上角展示“新建技能”下拉按钮。
- 下拉菜单第一项为“创建技能”。
- 点击“创建技能”后进入一个新的通用对话。
- 输入框自动填入“创建一个新的技能，这个技能的功能是：”，但不自动发送。
- 新对话自动选中 `skill-creator`，用户发送提示词时通过现有 `activeSkills` 会话创建流程提交该技能。
- 页面通过公共工具方法启动技能对话，不重复编排草稿状态、智能体切换、会话创建和路由跳转。

## 非目标

- 实现 ZIP、文件夹或 Markdown 技能上传。
- 修改 `skill-creator` 的实现或生成文件格式。
- 实现技能中心剩余的技能列表业务。

## 约束

- 复用现有的一次性对话启动意图和待激活技能机制。
- 用户可见文本必须使用国际化键值。
- 公共工具方法保留通用能力，不固化 `skill-creator` 或具体提示词。
