# 开放平台用户反馈（spec）

## 背景

开放平台顶栏目前只有「开发文档」。用户需要在文档入口右侧提交体验反馈，并查看自己的反馈记录。交互参照超级智能体网页端反馈抽屉：满意度评分、可粘贴截图的内容描述、反馈记录。

## 用户需求

1. 在开放平台顶栏「开发文档」右侧增加「用户反馈」按钮。
2. 点击后从右侧打开反馈面板，视觉跟随开放平台（浅底、圆角、主色 `#3a6cea`）。
3. 面板包含满意度评分（很差 / 较差 / 一般 / 很好 / 很棒）、内容描述、提交、反馈记录。
4. 内容描述支持直接粘贴截图，图片先上传再写入反馈正文。
5. 提交、上传、未读状态、反馈记录都走现有私有 API。测试包打到测试服，正式包打到 `https://c4ai.ccccltd.cn`，Product-Id 与 origin 成对。
6. 有未读回复时，按钮和「反馈记录」显示红点。

## 目标

- 顶栏可打开反馈面板，完成评分 / 图文提交，并查看本人反馈列表。
- 图片与正文按网页端契约提交：`comment` 为 HTML，图片地址为 `/api/sys-storage/download?f8s={fileToken}`。

## 验收标准

- 「用户反馈」位于「开发文档」右侧，点击打开右侧面板，可关闭。
- 未评分且无文字、无图片时不能提交；有评分或有内容时可以提交。
- 粘贴 png / jpg / jpeg 后先调用上传接口，成功后图片出现在输入区；提交正文里的图片地址是相对下载路径。
- 非图片、超过 10 张或单张超过 50MB 时不上传，并提示原因。
- 「反馈记录」展示当前登录用户的评分、摘要、时间和未读标记；无数据时有空状态。
- 接口经私有 API axios 实例发出，自动带 Fusion-Auth 与当前环境 Product-Id，不写死 token。

## 约束

- 不新增富文本编辑器依赖。粘贴只接受纯文本和图片。
- 展示历史图片时用带鉴权的下载转成 object URL，因为 `img` 无法带 Fusion-Auth。
- 登录凭据只从现有 `xkaitoken` 读取，不把用户提供的令牌写入代码。

## 非目标

- 不做反馈详情里的追评回复。
- 不改网页端反馈，也不改开放平台其它顶栏入口。
