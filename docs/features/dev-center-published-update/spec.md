# 开发者中心已发布应用更新

## 需求

- 本地登记应用的应用 ID 已存在于运行时应用目录时，开发者中心显示「更新」。
- 发布 / 更新弹窗中应用 ID 均不可修改并置灰，必须与本地登记应用一致。
- 提交更新时，最终 app.json 的应用 ID 必须与本地登记一致，版本号必须大于线上版本。
- 判重与版本基线统一读取运行时应用目录，后续从 OSS 替换为后端数据库时只替换目录数据源。

## 验收

- 已发布应用显示「更新」，未发布应用显示「发布」。
- 更新时应用 ID 输入框只读。
- zip 内 app.json 的应用 ID与当前应用不一致时提交失败。
- 已发布应用提交相同或更低版本时失败。
- 未发布应用首次发布不要求版本高于线上版本，但 ID 仍必须与本地登记一致。

## 非目标

- 不接入真实发布接口。
- 不修改应用创建、调试和运行来源切换逻辑。
