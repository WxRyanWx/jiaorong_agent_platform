# 插件中心连接器文案调整

## 需求

插件中心中原 MCP 菜单展示为「连接器」，原「连接器」菜单展示为「IM」，对应页面标题与内容同步调整。
交融应用菜单固定排在技能、连接器、IM 之后。
《开放文档-连接器.docx》的连接器启用方式需与当前客户端逻辑一致，不使用「安装」表述。

## 验收标准

- 两个插件中心壳的 MCP tab 均展示「连接器」。
- 原连接器 tab、页面标题、副标题和可用分组展示 IM 文案。
- 插件中心 MCP 页面标题展示「连接器」，内容改为连接器描述。
- 设置页原有 MCP 文案不受影响。
- 交融应用菜单位于插件中心导航最后。
- 连接器文档描述连接器卡片使用开关，而不是安装按钮。

## 非目标

- 不调整路由、组件结构、连接器/IM 业务逻辑和图标资源。
- 不实现开放平台连接器启用能力，仅修正文档表述。
