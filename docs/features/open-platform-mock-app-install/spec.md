# 开放平台 mock 应用安装与打开

## 用户需要

后端开放平台接口未接入前，插件中心的交融应用列表已经能展示 mock 发布记录。用户点击这些 mock 应用的安装按钮时，需要完成真实本地安装，并在安装成功后提供打开按钮。

## 目标

- 开放平台发布 mock 应用时记录本次发布使用的本地 zip 路径。
- 插件中心交融应用卡片在未安装时展示安装按钮。
- 点击安装后走现有应用包校验、解压与注册流程，并按应用 id 防止串包。
- 安装成功后刷新列表，并复用现有应用打开链路。

## 验收标准

- mock 应用未安装时展示安装按钮。
- 安装成功后列表中该应用展示打开按钮，点击可进入应用。
- 从任一插件中心壳打开应用后，点击返回必须回到该壳的交融应用列表。
- mock 应用同时是开发者中心登记应用时，安装状态仍能被插件中心识别。
- 安装包 id 与 mock 应用 id 不一致时安装失败并提示。
- 本地 zip 被移动或删除时安装失败并提示，不影响客户端继续运行。
- 两处插件中心壳复用同一应用中心组件，均获得该能力。

## 约束

- 不改变后端接口契约，mock zip 路径只保存在本地浏览器存储。
- 不引入固定示例包，避免所有 mock 应用都安装成同一个应用。
- 不新增独立安装实现，复用 `installAppFromPackage`。

## 非目标

- 不实现远端下载、鉴权、版本比对或后端市场能力。
- 不调整技能、连接器、IM 的安装逻辑。

## 待澄清

无。
