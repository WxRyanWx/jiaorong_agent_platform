# 开放平台后端接口契约精简版

状态：active
最后确认：2026-10-21

## 用户需求

- 原版《开放平台后端接口契约》信息量过大，后端阅读成本高。
- 需要一份精简版 Markdown，保留完整接口边界。
- 不采用原版“3 个统一接口”的写法，改为按模块和动作拆分接口。
- 每个接口必须写清入参、出参和返回数据结构；只保留必要字段约束。

## 验收标准

1. 覆盖交融应用、技能、连接器的列表、发布/更新、草稿、下架、重新上架、移除。
2. 不合并成 3 个泛化接口，接口职责边界清晰。
3. 保留鉴权、幂等、分页、时间格式；鉴权使用客户端现有 `Fusion-Auth` / `Product-Id` 请求头。
4. 不重复错误码，不描述服务端内部实现；只保留接口、数据结构和必要字段约束。
5. 每个返回数据结构必须用中文说明用途，`AssetSummary` 需要解释字段含义。
6. 保留新增 `auth.orgNames` 与 `auth.orgs` 的职责区分。

## 非目标

- 不复述服务端存储设计和开发顺序。
- 不展开客户端实现细节。
- 不新增接口或改变现有业务语义。
