# 交融默认模型切换 V4.1 Flash

## 需求

客户端不支持用户改模型，所有新对话使用交融内置默认模型。将默认模型从
`jiaorong-deepseek-v4-pro` 全局切换为 `jiaorong-deepseek-V4.1-flash`（服务端模型列表已确认该 ID 大小写）。

## 验收标准

1. 代码内默认模型 ID 全局替换；模型能力参数沿用原值不变。
2. 升级用户启动后：内置/手动交融智能体 config 中旧默认模型引用迁移为新模型；jiaorong 供应商下新默认模型自动启用、旧默认模型停用。
3. 新对话使用新默认模型；旧对话（已持久化 session 的模型）不迁移。

## 非目标

- 不修改模型能力参数（contextLength / maxTokens 沿用）。
- 不迁移旧会话的模型选择。
- 不做用户可见设置项变更。
