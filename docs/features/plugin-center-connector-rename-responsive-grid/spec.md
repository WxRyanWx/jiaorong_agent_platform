# 插件中心连接器命名与卡片自适应

## 需求

1. 插件中心「MCP」统一改为「连接器」：导航菜单、页面标题、新增按钮、搜索框占位文案。
2. 技能、IM、交融应用三个列表改为按容器宽度自适应列数，不再固定一行 3 个；窗口变窄时依次降为 2 列、1 列，避免卡片被过度压缩。

## 验收标准

- 插件中心两个壳（`/skills`、`/plugins`）左侧导航 MCP 项展示「连接器」。
- 插件中心连接器页标题展示「连接器中心」，新增按钮展示「新增连接器」，搜索框占位展示「搜索连接器...」。
- 设置窗口的 MCP 页保持原有「MCP」文案，不受本次改名影响。
- 技能 / IM / 交融应用 / 连接器四页在宽窗口保持 3 列，容器变窄时先降为 2 列、再降为 1 列，卡片不被压缩到不可用宽度。
- 四页在同一窗口宽度下列数一致、卡片宽度一致（间距统一 16px）。
- 四页搜索框统一：宽度随工具栏伸缩，最宽 360px、最窄 120px，剩余空间不足 120px 时整块换行。
- 四页筛选 tab（全部 / 已安装 / 未安装…）统一：字号 13、行高 18、高 32、左右内边距 18、圆角胶囊、底色 `#f2f3f5`、文字 `#646a73`、选中 `#006eff` 白字。
- 四页「新增」按钮统一：字号 14、字重 500、高 36、最小宽 118、内边距 0×20、圆角 8、图标 14。

## 约束

- 只改展示文案与样式，不改路由名、`serverName`、存储结构、MCP 协议字段。
- 用户可见文案走 i18n，全部语种键位保持对齐。
- 不改技能 / IM / 交融应用的安装、更新、打开、卸载逻辑。

## 非目标

- 不重命名 `skills-mcp` 路由与相关文件名、组件名。
- 不调整连接器页的启用、更新、详情、鉴权链路。
- 不新增依赖，不引入新的布局组件。

## 开放问题

无。
