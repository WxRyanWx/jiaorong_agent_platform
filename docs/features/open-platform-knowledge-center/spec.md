# 开放平台知识中心

## 用户需求

在开放平台首页、交融应用、技能、连接器后新增“知识中心”Tab，用 iframe 嵌入知识中心页面。URL 需按环境区分，测试地址已提供，生产地址暂缺。当前用户 token（`xkaitoken`）需追加到 URL 查询参数。

## 验收标准

- Tab 顺序为：首页、交融应用、技能、连接器、知识中心。
- 测试与生产统一使用 `http://106.63.7.106:10001/qa-platform-web/`，后续切换正式域名只改 `knowledgeCenter.ts` 一处。
- iframe URL 携带 `token=<当前用户 xkaitoken>`。
- 未取得 token 或未配置知识中心地址时有清晰兜底，不崩溃。
- 切到开放平台其它 Tab 或其它菜单再回来，知识中心保留原有会话与问答内容，不重新加载首页。

## 非目标

- 不实现知识中心页面本身。
- 不处理知识中心内部登录态。
