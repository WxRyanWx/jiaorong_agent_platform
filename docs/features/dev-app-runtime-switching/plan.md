# 实现方案

1. 开发者中心记录只保存在浏览器存储和主进程内存，不再在同步时长期写入 `.app-link.json`。
2. 打开调试窗口时临时写入 link，并确保该 appId 的旧进程先停止；关闭调试窗口时删除 link 并恢复扫盘结果。
3. 侧栏打开生产应用前先请求主进程检查调试窗口；确认后关闭调试窗口、删除 link、刷新应用缓存，再按生产目录启动。无 `spawn` 的生产应用按“已有 guest webview”判断运行中。
4. 打开调试窗口时发现生产进程运行，主进程弹出「取消 / 确定」确认框；确认后停止旧进程，再写入本地调试 link。
5. 确认切换到调试版时，主进程停止生产进程并通知所属渲染窗口移除生产 guest。
6. 卸载调试 link 只删除 `.app-link.json`，不改写本地源目录。
7. 应用中心更新或卸载同 id 应用前，先关闭调试窗口，确保操作生产安装目录。
8. 扫盘顺序固定为普通目录 → 系统应用 → 调试 link，保证调试窗口存在时来源确定，无调试 link 时恢复生产来源。

受影响链路：`createDevApp`、`syncDevApps`、`openDevAppWindow`、`JIAORONG_APP_OPEN_CHANNEL`、应用管理器扫盘。
