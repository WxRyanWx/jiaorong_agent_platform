# 开发者应用运行来源切换

## 需求

开发者中心允许登记与已安装/已发布应用同 id 的本地目录，并打开独立调试窗口。生产入口与调试入口共用一个 appId，同一时间只允许其中一个来源运行。

## 验收标准

- 创建本地应用时不因已安装/已发布同 id 应用失败。
- 开发者中心记录长期保留；只有调试窗口打开期间，本地目录才接管该 appId 的运行来源。
- 生产入口打开时，如调试窗口正在运行，先提示确认；确认后关闭调试窗口并恢复生产目录。
- 开发者中心打开时，如生产进程正在运行，弹出主进程确认框；确认后停止生产进程并使用本地目录。
- 侧栏菜单打开生产版本时，如调试窗口正在运行，弹出主进程确认框，按钮为「取消 / 确定」。
- 生产版本没有 `spawn` 进程但页面仍打开时，切换到调试版同样需要确认。
- 确认切换到调试版后，生产应用 guest 页面同步移除，后续重新打开调试版不重复弹确认。
- 生产与调试互相切换时只出现一个主进程确认框；确认文案直接使用中文。
- 同一来源重复打开时只聚焦，不重复弹确认。
- 移除开发者中心记录不删除本地目录，也不删除生产安装目录。
- 卸载调试 link 时不改写本地源目录的 app.json，未知自定义字段保持原样。
- 卸载非 link 应用但保留目录时，目录恢复后仍保持停用状态。
- 本地调试应用 id 必须符合单层 kebab-id 规则，且与开发者中心登记 id 一致，防止 link 路径逃逸。
- 应用中心更新或卸载同 id 生产应用前，先关闭本地调试窗口并释放临时 link。
- 系统应用自动更新遇到同 id 调试窗口打开时，跳过本次更新，不抢占调试运行来源。
- 调试期间修改本地 app.json.id 后，关闭调试窗口仍能按登记 id 清理临时 link。
- 调试期间修改本地 app.json.id 后，关闭调试窗口仍能停止以该本地目录运行的子进程。
- 生产应用打开请求尚未返回时切换到调试版，返回后不得再挂载旧生产 webview。
- 调试切换确认期间，登记目录或 app.json 发生变化时不写入临时 link。
- 登录用户变化时关闭调试窗口、清空开发者登记并释放临时 link。
- 并发打开同一个调试应用时，后完成的请求只聚焦已有窗口，不影响其运行进程。
- 旧生产 webview 迟到执行 leave 时，不停止已接管的调试进程。
- 应用中心更新 / 卸载前无条件执行调试来源清理，覆盖异常残留的临时 link。
- 调试窗口打开期间修改 app.json.id 时，调试 link 失效，不允许接管另一个应用 id。

## 非目标

- 不支持生产版与调试版同时运行。
- 不引入 `dev:<appId>` 独立运行身份。
- 不调整发布接口和版本校验。
