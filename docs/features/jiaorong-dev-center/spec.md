# 开发者中心

## 用户需求

- 开发者可在主窗口进入开发者中心，登记本地应用目录并调试。
- 已登记应用可打开独立调试窗口；窗口存活期间临时接管运行目录，关闭窗口即停止调试进程。
- 已登记应用可发布或更新：本地登记 ID 必须与最终 `app.json.id` 一致，更新版本必须大于线上版本。
- 开发者可移除本地登记；移除只影响开发者中心，不删除源码目录和生产安装目录。

## 当前行为

- 入口仅对远程配置 `developerPhones` 命中的身份可见。
- 创建应用时由主进程选择目录并校验 `app.json`。
- 本地登记按登录身份写入浏览器存储，并在刷新时同步主进程内存镜像。
- 调试窗口使用 `#/apps/<appId>?standalone=1`，内部渲染侧边栏与 webview。
- 生产与调试来源冲突时由主进程确认后切换，避免端口占用。
- 发布接口未接入后端前为本地占位；应用归属、ID 冲突和版本递增最终必须由服务端裁决。

## 验收标准

- 非开发者看不到入口与列表数据。
- 非法清单、非法 ID、版本未递增、发布 ID 与登记 ID 不一致时给出中文错误。
- 同一应用重复打开调试窗口只聚焦；关闭调试窗口停止对应目录进程并清理临时 link。
- 发布过程中不能取消、换包或打开其它发布弹窗。
- 刷新或重启后，当前登录身份的开发者登记可以恢复。

## 非目标

- 示例应用下载。
- 开发者中心独立入口窗口。
- 服务端发布上传与审批流。
