# 开发者中心 需求规格

## 用户需求

- 侧栏「搜索」按钮正上方新增入口（底部操作组第一个），所有人可见，不做权限控制；
  点击进去，页面 title 为「开发者中心」。
- 页面右上「创建应用」：弹系统目录选择器选插件文件夹，校验文件夹内 `app.json`
  必填字段（`id` / `name` / `version` / `entry`），缺失给中文提示，不入库。
- 示例应用由 OSS 配置 `devApp` 对象独立维护（不占 `apps` 目录）：
  `下载` = 选目录后把 `devApp.downloadUrl` 的 zip 下载到指定目录；
  `打开` = 与应用中心一致的打开逻辑（同 id 未安装不可打开）。
- 开发者创建的应用追加在示例应用之后：`打开`（同应用中心）、`发布`（弹窗表单：最终版
  app.json + 选择 zip 包，校验通过后提交）、`移除`（从本地名单去掉）。
- 卡片按钮顺序：`下载` / `发布` / `移除` 在左，`打开` 固定最右，整组右对齐。
- 入口点击后弹**独立窗口**（与设置窗口同思路），不再占用主壳页面；主窗口内路由仅作
  preload 桥缺失时的兜底。
- 独立窗口里点「打开」：回主窗口跳应用页并聚焦；主窗口不存在时才在独立窗口内就地跳。
- 开发者应用图标取所选文件夹 `app.json` 的 `icon`（旧名单在 sync 时回填）；示例应用图标
  优先取 OSS `devApp.icon`（http/https 绝对地址），未配时退回同 id 已安装目录的图标文件。
- 创建校验除必填字段外，还要过应用管理器登记规则（`slot` 三选一、`version` 三段式），
  否则 link 登记失败、Node 起不来，创建时就给中文提示。
- 开发者应用名单先在浏览器存储维护一份 `apps.json`（localStorage），后续替换为服务端接口；
  发布确认逻辑接口未给，暂为本地成功占位。
- 应用中心与开发者中心在 `appHost` 下各自成独立模块目录。

## 验收标准

- 任意登录用户都能看到入口并进入页面；列表 / 创建 / 发布 / 选包 / 示例下载 / 打开独立窗口
  全部不校验开发者身份。
- 应用中心可见性不变：仍走 OSS `appCenterVisiblePhones` / `developerPhones`。
- 创建应用：目录无 `app.json`、必填缺失、`slot` / `version` 不合规 → toast 中文说明，名单不变。
- 创建成功：卡片立即出现，图标为所选文件夹的 `icon`，可直接打开（Node 由 link 登记后 spawn）。
- 独立窗口：无主壳侧栏 / AppBar；macOS 顶部留拖拽区；toast 在独立窗口内可见。
- 独立窗口点「打开」：主窗口切到该应用页并聚焦，独立窗口保持打开。
- 示例应用下载：zip 落到用户所选目录，结束即释放流。
- 发布弹窗确认：当前返回成功占位并 toast 提示接口待接入。
- 刷新 / 重启后开发者名单仍在（localStorage 恢复并同步主进程）。

## 约束

- 主进程 Presenter 边界不变：目录选择、manifest 校验、下载都在主进程。
- 用户可见文案走 i18n 全 locale。
- 不改动应用中心既有安装 / 更新 / 卸载语义。

## 非目标

- 服务端发布接口与云端 apps.json（接口未给）。
- 开发者应用的版本比对 / 更新提示。
- 示例 zip 内图标解析（不解包取图，图标走 `devApp.icon` 或已安装目录）。

## 开放问题（已按假设关闭）

- 入口位置：侧栏搜索上方独立按钮（与用户描述「搜索上面」一致）。
- 示例应用：取 OSS 目录中 `app-scaffold`，缺失时退回首个 zip 应用；都没有则不展示示例卡。
- 发布确认：表单校验（最终版 app.json 必填齐全 + zip 存在）通过后占位成功，toast 说明接口待接入。
- 配置键名：`devApp`（兼容小写 `devapp`）。
