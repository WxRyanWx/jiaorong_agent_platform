# 交融应用声明支持的客户端

## 需求

`app.json` 增加可选数组 `platforms`。里面写这个应用支持哪些客户端。

客户端一共 6 个：`windows-x64`、`windows-arm64`、`linux-x64`、`linux-arm64`、`mac-x64`、`mac-arm64`。

- 没有这个字段：6 个客户端都能安装、打开、更新、卸载。
- 写了这个字段：只有列出的客户端可以。例如 `["windows x64"]` 只支持 Windows x64。
- 空数组，或里面没有一个能认出的系统：所有客户端都不支持。

不支持的客户端上，卡片和详情里的安装、打开、更新、卸载、钉到菜单、打开方式都隐藏，改成「该应用不支持当前系统」。详情按钮保留。

大小写、空格和下划线忽略。`windows x64`、`Windows-X64`、`win-x64` 都是 Windows x64。`macos`、`darwin`、`osx` 都是 Mac。

## 验收

1. 已安装包按磁盘 `app.json` 判断。未安装时，目录或安装包里的 `app.json` 能读到也按它判断。
2. 读不到声明时先保持原按钮。点安装会在解包后拒绝，并提示同一句文案。
3. 不支持的应用不出现在侧栏，主进程也不启动它。
4. 开发者中心调试窗口仍可打开本地目录，方便在当前机器上调试只面向其他系统的包。
