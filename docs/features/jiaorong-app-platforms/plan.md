# 实现

`platforms` 只在字段出现时写入清单。缺省表示全部客户端。

判断集中在 `appHost/platforms.ts`。卡片用 `supportedOnClient === false` 隐藏操作。已装包读磁盘清单；目录接口如果带回 `platforms` 也认；否则对未安装或有更新的包读取 zip 尾部的 `app.json`，按 sha256 记在本机，避免每次都下整包。服务器不支持分段下载时，安装解包后再拒绝。

安装和系统包更新在覆盖旧目录之前拒绝。打开在拉起 Node 之前拒绝。卸载按钮隐藏，但卸载接口仍可用，避免已经落盘的包删不掉。

## 测试

纯函数覆盖缺省、`windows x64`、空数组和 zip 内清单。不依赖当前机器的系统。
