# 开放平台发布组织

## 用户需要

发布交融应用、技能、连接器时，发布者必须填写发布组织；市场卡片展示该组织，避免出现「本地」这类来源文案。

## 目标

- 交融应用发布弹窗提供必填的发布组织输入框。
- 技能、连接器管理卡片在发布状态右侧提供必填的发布组织输入框。
- 未填写发布组织时，发布、更新、重新发布不可用。
- 市场卡片展示「由 xxx 提供」。

## 验收标准

- 发布请求携带统一 `provider` 字段。
- 必填标签使用红色星号，并采用「* 字段名：输入框」布局。
- 插件中心交融应用卡片展示发布组织，不展示「本地」。
- 技能市场卡片左下角展示发布组织。
- 连接器市场卡片右上角展示发布组织。
- 后端未返回 `provider` 时不崩溃，仅不展示组织文案。

## 约束

- `AssetSummary.provider` 对旧数据保持可选。
- 不改变可见范围 `auth.orgNames` 语义。
- 交融应用组织权限改为匹配用户 `orgList[].pathNo` 的组织路径节点；无 `pathNo` 的存量数据回退匹配 `orgNo`。

## 非目标

- 不做组织联想、组织 ID 校验或组织管理。

## 待澄清

无。
