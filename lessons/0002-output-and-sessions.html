Lesson 2 · 约 12 分钟

选择正确输出，并跨进程继续

把“模型回答了”升级成机器可以可靠消费的终态。

本课成果：你能解释三种输出差异，并用上一课 Session 在第二个进程中继续。

1. 三种输出

格式适用终态
text人直接阅读stdout 最终正文
json普通脚本一个结果对象
stream-json实时 UI、工具和取消首个 init、末个 result
jiaorong-cli -p '简短回答' --model MODEL_ID --output-format text
jiaorong-cli -p '简短回答' --model MODEL_ID --output-format json
jiaorong-cli -p '简短回答' --model MODEL_ID --output-format stream-json

JSONL 中，message.delta 拼成正文，tool_use/tool_result 按 toolCallId 配对，唯一 result 才是最终事实。stderr 不能混入 stdout。

2. 恢复 Session

jiaorong-cli \
  -p '上一轮要求你记住的内容是什么？' \
  --resume SESSION_ID_FROM_LESSON_1 \
  --output-format json

CLI 只发送新 Prompt，历史由 JiaorongAI 持久化。不同 Session 可并行；同一个 Session 不可同时被两个 CLI 进程或桌面端占用。

练习

  1. 第一进程要求模型记住一个随机暗号。
  2. 关闭命令后，用第二个进程和 --resume 提问。
  3. 确认第二轮返回同一个 Session ID。
自测：进程退出但没有 result，能否算成功？

不能。缺失 Terminal Result 是协议或传输失败。
