给任务最窄的文件权限

Project Root、Attachment、Additional Directory 和 full_access 是四个不同概念。

本课成果：你能安全传入文本文件，并只授权一个明确的外部目录。

1. Project Root

命令的当前工作目录就是 Project Root。不要为了方便从 Home 或 / 启动文件任务。

cd '/absolute/project-root'
jiaorong-cli -p '只分析当前项目，不修改文件' --model MODEL_ID

2. 文本 Attachment

jiaorong-cli \
  -p '比较两份文本附件' \
  --file ./before.md \
  --file ./after.md \
  --model MODEL_ID \
  --output-format json

首版使用 plain text、Markdown 和 JSON。每次最多 16 个文件，单个 30 MiB，总计 60 MiB。图片真实识别不在首版范围。

3. 外部目录和文件工具

jiaorong-cli \
  -p '读取外部资料中的 notes.md，并更新当前项目摘要' \
  --permission-mode full_access \
  --add-dir '/absolute/reference-materials' \
  --model MODEL_ID \
  --output-format stream-json

full_access 只允许经过关联校验、且目标位于 Project Root 或显式 Additional Directory 的 Read、Write、Edit、Glob、Grep 请求。它不是全盘权限。Shell 的 exec/process 永远禁用。

练习

  1. 新建一个只含随机 canary 的文本文件。
  2. 用 --file 让模型复述它。
  3. 把文件移到 Project Root 外，观察未加 --add-dir 时的拒绝。
  4. 只授权文件所在的最窄目录后重试。
自测：full_access 能否读取任意路径？

不能。Project Root 和 Additional Directory 仍是硬边界。
