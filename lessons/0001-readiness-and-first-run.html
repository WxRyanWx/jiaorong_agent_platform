确认你连接的是正确的 JiaorongAI

先建立可靠反馈回路，再运行第一条真实文本任务。

本课成果：你能确认 CLI、App、endpoint 和模型，并得到一个带 Session ID 的成功 JSON。

1. 四步 readiness

command -v jiaorong-cli
jiaorong-cli --version
jiaorong-cli doctor --output-format json
jiaorong-cli models list --output-format json

要求：版本为 0.1.0；Doctor 的 ok=true；App 为 0.5.6；endpoint 是 loopback；至少一个模型 available=true。authentication: warn 是预期状态，真正运行时才验证 Provider。

2. 第一条任务

cd '/absolute/project-root'
jiaorong-cli \
  -p '只输出 FIRST_RUN_OK，不要解释，不要调用工具。' \
  --model jiaorong/jiaorong-deepseek-v4-pro \
  --output-format json \
  --timeout 60

保存返回的 sessionId。成功条件不是“看到了回答”，而是 exit 0、status=success、error=null 和非空 Session ID 同时成立。

练习

  1. 运行四步 readiness。
  2. 把模型 ID 换成目录里当前 available 的准确 ID。
  3. 执行 canary，并把 exit、status、content、sessionId 四项抄下来。
自测：Doctor 的 authentication warn 是否表示登录失败？

不是。0.5.6 没有只读凭据有效性信号，实际 run 才会检查 Provider。
