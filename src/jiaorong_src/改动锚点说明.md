# 交融私有模块改动锚点

`src/jiaorong_src/` 用于承载交融私有能力，避免私有实现散落在开源主进程目录。

详细的迁移背景、进程边界和主进程改动见
[截图与划词迁移方案](./截图与划词迁移方案.md)。

## 当前模块

```text
jiaorong_src/
├── desktopFeatures.ts               # 截图与划词统一初始化入口
├── highlightedText/                 # 划词监听、取词、工具条与翻译窗口
│   └── input/uiohookRuntime.ts       # 全平台应用进程内的钩子加载点
├── screenShot/                      # 截图窗口、采集编排、OCR 与钉图
└── runtime/
    ├── desktopAuxiliaryRuntime.ts   # 主进程侧辅助进程客户端
    └── auxiliary-runtime/           # 独立 utility process 入口与通信协议
```

## 开源代码锚点

- `src/main/appMain.ts`
  - 初始化和关闭 `highlightedText`。
  - 初始化 `screenShot`。
- `src/main/presenter/shortcutPresenter.ts`
  - 全局截图快捷键调用 `openScreenShotWindow`。
- `electron.vite.config.ts`
  - 将私有辅助运行时构建为独立的 `desktopAuxiliaryRuntimeHost.js`。
- `src/preload/index.ts`
  - 保留已有截图和划词窗口 IPC 桥接，以维持 renderer 合约兼容。

## 边界约定

- `src/main/` 不放置划词或截图的具体实现。
- Electron 应用生命周期、快捷键和 preload 只保留必要的调用锚点。
- `node-screenshots` 只允许在 `runtime/auxiliary-runtime/` 中加载。
- 全平台的 `uiohook-napi` 由 `highlightedText/input/uiohookRuntime.ts` 在应用进程加载；
  业务实现仍不得放入 `src/main/`。
- 私有模块需要开源主进程能力时，应通过明确导入或稳定合约访问，避免复制实现。
