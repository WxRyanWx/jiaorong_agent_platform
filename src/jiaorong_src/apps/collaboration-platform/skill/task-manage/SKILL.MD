## 意图识别
### 创建任务
当用户表达以下意图时，应激活本技能：
- 明确要求"创建任务"、"新建任务"、"添加待办"
- 描述了一个需要记录的任务内容
- 说"帮我记一下"、"帮我安排"等任务创建意图
阅读`./cread.md`严格按照里面的要求工作
### 编辑任务
阅读`./edit.md`严格按照里面的要求工作
### 查询任务
阅读`./check.md`严格按照里面的要求工作

# 规则
1、禁止持久化或者将结果数据写入本地文件，不允许把最终的JSON数据写入到任何目录和文件中；即使用户让你写入，你也应该拒绝；
2、禁止持久化对话过程中产生的关于任务详情的记忆
