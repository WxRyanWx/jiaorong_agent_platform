## 1. 技能中心（列表页）

增加“技能中心”模块。

技能中心的技能有两个来源：

1. **系统内置技能**：随安装包一起安装到用户本地，主要是文档读写、系统接管等工具类技能。
2. **中交 SkillHub 技能**：后续技能社区由 SkillHub 维护，客户端需自动打通并获取技能。

> 原型图中的分类标签仅为示意，实际开发标签将在后续补充。

![技能中心列表页](</Users/yanxia1/Desktop/编辑 - V0.6 增加技能模块 _ 知识库管理_files/yUINxzLZGxmkha-U31Ob3wW6owzsniMcnzRglQVfuDQ.png>)

技能市场中的技能分为两种状态：

- **未安装**：卡片按钮显示“安装”。
- **已安装**：卡片按钮显示“使用”。

## 2. 安装技能

用户点击“安装”后，系统自动将技能对应的文件（`.md`、`.py`）放到指定目录下。

按钮交互流程：

1. 用户点击“安装”。
2. 按钮短暂显示“安装中”，并处于禁用状态。
3. 安装完成后，按钮变为“使用”。

![技能安装状态](</Users/yanxia1/Desktop/编辑 - V0.6 增加技能模块 _ 知识库管理_files/Tz-BZSDFgWHd78c07EUdtLvUg081oQEYlhs7wLKzJbU.png>)

## 3. 技能详情

点击技能卡片进入技能详情页。详情页根据技能是否已安装展示不同内容。

### 3.1 未安装的技能详情页

只显示：

- 技能名称。
- 技能描述。
- 安装按钮。

![未安装的技能详情页](</Users/yanxia1/Desktop/编辑 - V0.6 增加技能模块 _ 知识库管理_files/wsp-jxlDcS3e2bte7jWxbJd4TZ8YStpX6WXlu-o8k5o.png>)

### 3.2 已安装的技能详情页

页面从上到下依次显示：

1. **技能名称与启停开关**
   - 启停开关默认开启。
   - 用户关闭后，对话中无法通过 `/` 呼出该技能，智能体也不会调用该技能。
2. **技能描述**。
3. **技能操作列**
   - 使用。
   - 打开文件夹：打开本技能存放的本地路径，需提供 Tooltip 提示。
   - 卸载技能：删除技能文件，使技能恢复为未安装状态，同时将当前页切换为未安装页面；需提供 Tooltip 提示。
4. **试一试**：携带技能和预设提示词跳转到对话页面。
5. **源文件**：支持两种查看方式：
   - Markdown 源文本。
   - Markdown 转换后的渲染样式。

## 5. 新建技能

新建技能有三种方式：两种显性方式和一种隐性方式。

### 5.1 通过自然语言对话和 skill-creator 创建

![通过自然语言创建技能](</Users/yanxia1/Desktop/编辑 - V0.6 增加技能模块 _ 知识库管理_files/pYw1s7kKS_jMIkEPSIsISIJPlat0Cet5OrfS4ZnXtBs.png>)

当前模式存在的问题：技能初次创建完成后，不能直接通过 `/` 呼出，需要调整新技能的存放目录和文件格式。

本次开发要求：

- 改造 skill-creator 技能，将生成的技能按照客户端要求的路径和文件格式放入指定位置。
- 最好增加一次用户确认：

  > 是否将新创建的技能按照客户端要求调整文件格式并置入指定路径，实现通过 `/` 自动呼出的效果？

### 5.2 通过上传文件创建

支持上传以下三种格式：

- ZIP 压缩包。
- 文件夹。
- Markdown 文件（`.md`）。

本次上传功能不校验文件内容的合规性，只校验文件格式。入口位于技能中心右上角。

![上传文件创建技能](</Users/yanxia1/Desktop/编辑 - V0.6 增加技能模块 _ 知识库管理_files/2ErQcGwh5oNLE5IEVzlaepM0Ra6t3zv0-HGLGQHOH0Q.png>)

当前 Windows 系统技能路径为：

```text
C:\Users\<系统用户名>\.deepchat\skills
```

各上传类型的处理方式：

- **文件夹**：直接放到技能目录下。
- **ZIP**：解压后放到技能目录下。
- **Markdown 文件**：创建与 `.md` 文件同名的文件夹，再将 `.md` 文件放入该文件夹。

### 5.3 用户手动操作文件夹创建

用户可以手动进入系统目录添加技能。这是无法避免的隐性操作。

本次无需针对此方式开发额外功能，技能能否被识别和使用由 DeepChat 现有机制决定。

### 5.4 自主创建技能的展示

通过上述三种方式自主创建的技能，需在技能中心中显示对应卡片：

- 最低要求是显示技能名称。
- 描述信息可能不存在。
- 如果 Markdown 文件符合要求的格式，可以解析并显示描述信息。

## 7. 其他设置说明

### 7.1 复用 DeepChat 原生上传入口

DeepChat 本身已提供上传技能的安装入口：

- 不支持 `.md` 文件。
- 额外支持 URL。

如果新的上传功能开发困难，可以复用 DeepChat 现有服务，在新技能中心中提供一个入口唤起原生弹窗。

![DeepChat 原生技能安装入口](</Users/yanxia1/Desktop/编辑 - V0.6 增加技能模块 _ 知识库管理_files/dRKMoArfXUVdk8xoMAU0wYog9a5baRhWcy2D6VsaGh4.png>)

### 7.2 隐藏 DeepChat 原生 Skill 设置

本次功能与 DeepChat 原生技能管理有较多重复，但新设计更适合中交集团用户，因此：

- DeepChat 原生 Skill 设置菜单继续保持隐藏，不对用户展示。
- Skill Draft 功能始终默认关闭。

![DeepChat Skill 设置](</Users/yanxia1/Desktop/编辑 - V0.6 增加技能模块 _ 知识库管理_files/_zIDE_-ak1DFUgPR6Mgmv1cMtAsPbdIgsRBzahN4KgI.png>)
